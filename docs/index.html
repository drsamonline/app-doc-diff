Clause by clause

The comparison is line by line, not a paragraph diff. A clause that moved without changing is shown as unchanged, so a reorder is not mistaken for a rewrite.

What it refuses

It will not summarise. There is no “3 changes found” without showing them — a summary of a contract is the thing you would have to check anyway.

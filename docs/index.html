Doc Diff

Compare two documents and see exactly what changed, clause by clause. A reflowed paragraph is not a change. A reworded clause is one finding.

What it does

  • Splits both documents into clauses — by paragraph, list marker and sentence — and compares clause to clause.
  • Ignores what is not a change in meaning: reflowed lines, renumbered clauses, a clause that moved.
  • Reports a reworded clause as one finding, with the before and after text and a similarity score.
  • Reports additions and removals separately, at the place they occur.
  • Says "cannot tell" when two clauses are close but not the same, instead of guessing.
  • Exports the delta — the findings only, not the two documents — as Markdown or JSON.

What it will not do

  • No word-level or character-level colouring. The question is what changed in meaning.
  • No server, no account, no telemetry, no network call at runtime. The two documents never leave the device.
  • No storage: nothing is kept between visits. If you want the result, export it.
  • No invented confidence: an empty document is reported as empty, not as "everything removed"; a document it cannot read is refused by type.

When things go wrong

CaseWhat happens
Bad inputThe file is refused with its type, and nothing is compared.
No networkNothing changes — the app never needed one.
Storage full or unavailableThe comparison still runs in memory; the export fails and says the file was not written.
Corrupt saved stateThere is no saved state. A damaged or binary file is refused at open, with the reason.

How to run it

  • Here: play/index.html, or install it as an app from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk — no server, no build step.
  • Tests: node tests/self-tests.js — every "must not" above is a named assertion in that file.
